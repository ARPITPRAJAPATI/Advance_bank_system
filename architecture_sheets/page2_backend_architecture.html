1. CLIENT & INGRESS PERIMETER PORT 80 / 31100
React 19.2 + Vite Client SPA Vercel/Nginx
• Virtual RuPay 3D Card: Mathematical spring physics (TiltCard.jsx) with mouse-tracking matrix transforms.
• Idempotency UUID: Browser generates crypto.randomUUID() before HTTP POST payload dispatch.
• Zero-Storage Security: Tokens are NEVER written to localStorage (XSS immune).
Nginx 1.31 Reverse Proxy & Ingress Reverse Proxy
• Route Splitting: Static SPA served at root /, dynamic routing passes /api/* to Express microservice.
• Header Enforcement: Injects X-Content-Type-Options: nosniff, X-Frame-Options: DENY, Strict CSP.
• CORS Shield: Explicit credentials reflection for withCredentials: true cross-origin session binding.
Security Perimeter & Session Guard Auth Shield
• JWT Cookie Transport: Signed with HS256 secret, delivered via HttpOnly, Secure, SameSite: Lax.
• Token Revocation Engine: On logout, token JTI hash written to blacklisted_tokens collection with TTL index.
• PII Sanitizer Middleware: Strips credit card CVVs and account passwords from all debug access logs.
2. CORE TRANSACTION ENGINE & ACID COORDINATOR ATOMIC SESSIONS
ACID Multi-Document Isolation Protocol session.withTransaction()
• Read Concern: majority — guarantees reads reflect fully committed, non-orphaned node state.
• Write Concern: w: "majority", j: true — commits only after disk journal fsync across replica quorum.
• Race Condition Defense: In-flight requests lock sender account in memory/DB; parallel debit requests fail immediately with 409 Conflict instead of causing negative balance overdraft.
Two-Layer Daily Reconciliation Engine Automated Audit
• Layer 1 (Runtime Invariant): Balance is a computed aggregate: Balance = Σ(CREDIT) - Σ(DEBIT). Database stores zero raw mutable balances.
• Layer 2 (Nightly Reconciler): Cron job sweeps entire ledger_records database, compares mathematical totals against transaction tables, and raises immediate Slack/email alerts on any ledger drift.

🎯 Interview Defense: Why Double-Entry Ledger? "Single-table balances are vulnerable to silent update corruption. By recording immutable DEBIT/CREDIT pairs, every single rupee can be audited back to day 1. If sum of debits doesn't match sum of credits across the bank, the system halts."
⚡ Concurrency & Double-Spend Defense: "We combine client-side UUID idempotency with MongoDB session.withTransaction() under majority write concern. Duplicate clicks replay the exact same receipt without re-running ledger operations."
🔒 Zero-Trust Auth Architecture: "Tokens are housed strictly in HttpOnly, SameSite: Lax cookies — making JavaScript document access and XSS theft impossible. Explicit token blacklisting handles immediate server-side session revocation."
